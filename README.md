# Hull Down

BattleZone Reimagined — a "slightly" more modern take on Atari's 1980
first-person tank game, built in Godot 4.

## Status

First real build — VECTOR mode: you drive a tank first-person across a
green line-drawn plain (ground grid, box and pyramid obstacles, a
mountain ring on the horizon) and fire the cannon. No enemies or radar
yet. The in-game options show VECTOR active and 3D MODELS disabled —
that mode arrives later and reads the same game state.

Controls: W/S or arrows drive, A/D turn, Space fires, F11 fullscreen.
The display stretches to fill any window or published screen.
